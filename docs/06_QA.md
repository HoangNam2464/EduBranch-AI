## 1. CHIẾN LƯỢC KIỂM THỬ ĐA TẦNG (MULTI-TIER TESTING STRATEGY)

Hệ thống EduBranch AI áp dụng mô hình kim tự tháp kiểm thử nghiêm ngặt bao gồm 5 tầng phòng thủ:

```text
                  ┌───────────────────────────────┐
                  │    UAT & Release Readiness    │  (QA-017, QA-019)
                  ├───────────────────────────────┤
                  │ Accessibility & Cross-Browser │  (QA-018)
                  ├───────────────────────────────┤
                  │     E2E Flow & Safety Audit   │  (QA-011, QA-014, QA-015, QA-016)
                  ├───────────────────────────────┤
                  │ Integration & Invariants Test │  (QA-005, QA-008, QA-009, QA-012, QA-013)
                  ├───────────────────────────────┤
                  │ Unit, Security & Schema Test  │  (QA-001, QA-002, QA-003, QA-004, QA-006, QA-007, QA-010)
                  └───────────────────────────────┘
```

### 1.1. Tầng Backend Gateway (NestJS + Jest / Supertest)
- **Unit Tests**: Kiểm tra tính độc lập của Service, Repository, DTO validation (`class-validator`), Migration runner.
- **HTTP Security E2E (Supertest)**: Kiểm tra trực tiếp qua `JwtAuthGuard` và `RolesGuard`:
  - Chặn request không có Bearer token (401 Unauthorized).
  - Chặn truy cập chéo giữa Lecturer và Student (403 Forbidden).
  - Chặn sinh viên truy cập case chưa xuất bản (`DRAFT`, `REVIEWED`, `APPROVED`).
  - Chặn giảng viên can thiệp hoặc xem case/material của giảng viên khác (Ownership isolation).

### 1.2. Tầng AI Service (FastAPI + pytest + httpx)
- **Graph Theory & Decision Tree Invariants**:
  - Thuật toán DFS 3-color phát hiện chu trình (cycle detection).
  - Kiểm tra tính liên thông (reachability) từ Root Node.
  - Bắt buộc tồn tại ít nhất 1 Terminal Node.
- **RAG & Retrieval Boundary**:
  - Đóng gói dữ liệu truy xuất trong thẻ `<sources>...</sources>` (Untrusted context boundary).
  - Chặn prompt injection qua tài liệu giảng dạy.
- **Socratic Challenge Safety**:
  - Khống chế tuyệt đối tối đa 2 vòng đối thoại (hard cap).
  - Tuyệt đối không sinh phản hồi chấm điểm, xếp hạng hoặc kết luận pass/fail.

### 1.3. Tầng Frontend (React 19 + TypeScript)
- Strict type checking không có lỗi TypeScript (`tsc -b`).
- Build kiểm thử tự động với Vite (`vite build`).
